# 땡큐와인 회원 '내 와인' (2026-11-24)

로그인한 회원이 매장에서 산 와인을 모아 보고, **산 와인에만** 별점(1~5)과 한 줄 메모를 남겨요. 가격은 어디에도 없어요.

## 페이지
- `/login/` 카카오·구글로 시작 (필수 동의: 만 19세, 개인정보 수집·이용)
- `/me/` 내 와인: 산 와인 목록(최근 산 순서, 같은 와인은 한 장), 별점·메모, '다시 주문하기'(문의 창), 내 정보(이름·휴대폰), 로그아웃·탈퇴
- `/admin/` 관리자: 장부 파일 열기 → 연결 기다리는 회원을 장부 손님과 연결 → 구매 내역 반영
- 세 페이지는 검색에 안 나와요(noindex, robots, 사이트맵 제외). 메뉴 '내 와인'은 `tools/build.py` 의 `MEMBERS_OPEN` 으로 켜고 꺼요.

## 구매 내역이 들어오는 길
1. 손님이 가입하고 휴대폰 번호를 남겨요.
2. 비서실(Claude)이 장부(아티팩트 db members·sales)를 내려받아 `python3 tools/ledger_export.py <폴더> <파일.json>` 으로 파일을 만들어요.
   파일엔 손님 이름·번호와 구매 줄(날짜·와인 이름·병 수)만 있고 가격·주소·메모는 없어요. **공개 저장소에 올리지 말고** 프로젝트 파일 폴더에만 둬요.
3. 관리자가 `/admin/` 에서 파일을 열면(브라우저 안에서만 읽음) 번호가 같은 장부 손님을 미리 골라 둬요. 본인이 맞는지 보고 '연결'.
4. 연결한 회원의 구매 줄만 Supabase 에 올라가요. 새 구매는 파일을 다시 열고 '연결된 회원 구매 내역 새로 반영'.

번호만으로 자동 연결하지 않는 이유: 휴대폰 인증이 없어서 남의 번호를 적으면 남의 구매 내역이 보일 수 있어요. 관리자가 한 번 확인하는 게 가장 안전해요.

와인 이름은 사이트 와인 목록(`tools/wines.json`)에 맞춰 사진·소개 글을 붙여요. 못 맞춘 이름은 장부 이름 그대로 보여요(괄호 속 메모는 지움). 맞추려면 `tools/ledger_alias.json` 에 `"장부 이름": "목록 이름"`.

## 켜는 순서 (Supabase 는 코르크매치와 같은 프로젝트)
1. Supabase → SQL Editor 에 `docs/supabase-thankyou.sql` 붙여넣고 Run.
2. Authentication → URL Configuration → Redirect URLs 에 추가:
   `https://thankyouwine.vercel.app/**`, 미리보기용 `https://*-doha17.vercel.app/**` (도메인 붙이면 `https://thankyouwine.com/**` 도)
3. 카카오·구글 로그인은 코르크매치에서 켠 것을 같이 써요. 꺼져 있으면 버튼 대신 '곧 열려요'가 보여요.
4. 관리자는 코르크매치 `admins` 표에 있는 계정이에요(같은 계정으로 로그인).

## 서버 규칙 요약 (`docs/supabase-thankyou.sql`)
- `ty_profiles` 본인만 읽고 씀, 관리자 보기 · `ty_links` 관리자만 만들고 지움 · `ty_purchases` 연결된 본인 것만 보기
- `ty_reviews` 본인만, 산 와인(`ty_bought`)일 때만 쓰기 · 연결을 끊거나 계정이 지워지면 구매 줄도 지워짐
- `ty_leave()` 땡큐와인 탈퇴: 땡큐와인 정보 삭제, 코르크매치·비노나루를 안 쓰면 로그인 계정도 삭제

## 2단계 (별점이 쌓인 뒤)
설계 메모: 프로젝트 파일 `땡큐와인/회원/2단계_취향요약_추천_설계.md`

## 선불권 (11/24 추가)
- 연결된 회원은 '내 와인' 위에서 선불권 잔액과 충전·사용 내역을 봐요(본인만, 선불권이 있을 때만 보임). 표 `ty_prepaid`.
- 장부 판매 중 결제방식 '선불권'은 사용, 품목에 '선불권'이 든 판매는 충전으로 자동으로 들어가요. 판매에 없는 충전(보너스 포함)·사용은 프로젝트 파일 `땡큐와인/회원/선불권.json`에 적고 `ledger_export.py`의 세 번째 인자로 넘겨요.
- 사용 줄 이름에서 다른 사람 이름(OO 대표님 등)은 지워요.

## 찜하기 · 평균 별점 · 인기 배지 (11/24 추가)
- 와인 카드·와인 페이지에 하트(찜). 로그인 전엔 그 브라우저에만 저장하고 "이 기기에만 저장돼 있어요, 로그인하면 어디서든 모아 봐요" 안내. 로그인하면 계정(`ty_saves`)으로 옮겨요. 내 와인 페이지에 찜한 와인 목록.
- 평균 별점: 회원 별점이 3개 이상 쌓인 와인만 보여요(한두 명이면 누가 남긴지 짐작 가능).
- '많이 찜한 와인': 찜 3개 이상인 와인 중 상위 10개. '문의 많은 와인': 최근 30일 문의 버튼 5번 이상인 와인 중 상위 10개(한 브라우저에서 와인마다 하루 한 번만 셈, 누가 눌렀는지는 안 남김).
- 숫자는 `ty_wine_stats()` 한 번 호출로 받아 와요. 데이터가 없으면 아무것도 안 보여요.
